# 문장 조립소 · Sentence Studio

고등학생이 영어 어구를 배열하며 어순과 구문을 복습하는 웹앱입니다.

## 실행

`node preview.cjs` 실행 후 http://127.0.0.1:8765 에 접속합니다. 또는 dist/index.html을 브라우저에서 엽니다. 외부 라이브러리 설치가 필요하지 않습니다. 글꼴을 불러오지 못하면 시스템 글꼴을 사용합니다.

## 사용

- 학생 모드: 어구 선택, 선택 취소, 다시 놓기, 힌트, 정답 확인, 오답 복습.
- 교사 모드: 한 줄에 한 문장, 어구는 `/`, 선택적인 한국어 뜻은 `|`로 구분합니다.
- 예: `Small actions / can make / a big difference. | 작은 행동이 큰 변화를 만들 수 있다.`
- 활동은 브라우저 localStorage에 저장됩니다. 다른 기기와는 자동 동기화되지 않습니다. JSON 내보내기·가져오기로 전달합니다.
- 학습 진행 상황은 현재 세션에서만 유지됩니다. 새로고침하면 초기화됩니다.
- 정답 판정은 교사가 입력한 어구 순서를 기준으로 합니다. 다른 문법적 정답을 자동 인정하지 않습니다.
- 예제 5문장은 시연용입니다. 로그인, 학생 실명, 서버 성적 수집 기능은 없습니다.

## 검증

`node --check dist/app.js` 및 `node test.cjs`.
test.cjs는 DOM 대역을 사용하는 동작 검사이며 실제 브라우저 렌더링·모바일 검증을 대신하지 않습니다.

### 2026-11-26: 문제 중심 화면과 문장 성분 힌트

- 소개를 짧게 줄이고 650px 이하에서는 문제를 활동 목록보다 위에 배치했습니다. 상단 '활동 바꾸기'로 목록으로 이동할 수 있습니다.
- '문장 성분 힌트'를 펼치면 예제 5문장의 구조와 해설이 표시됩니다. 색상뿐 아니라 주어·동사 등 글자를 함께 사용합니다.
- 이는 자동 분석이 아닙니다. 문장 전체가 준비된 예제와 일치하는 경우에만 해설을 제공합니다. 난이도 변경과 예제 파일 내보내기·가져오기 이후에도 동일 문장이면 사용 가능합니다.
- 단어 단위에서도 개별 단어를 주어·동사로 잘못 분류하지 않고 구·절 전체의 성분을 보여줍니다. 5번 비교 구문은 두 절을 구분합니다.
- 전체 문장 순서가 드러나는 도움말임을 미리 알리고, 열어본 횟수를 다음 어구 힌트와 별도로 기록합니다. 정답을 맞혀도 힌트를 사용하지 않은 것처럼 안내하지 않습니다.
- 성분 힌트는 문장·난이도 전환 때 접힙니다. 새로고침 후 진행 기록은 유지되지 않습니다.
- 문법 설명 데이터는 dist/grammar.js입니다. 단위 테스트와 실제 브라우저에서 펼침·접기, 복문, 기존 활동의 비활성 안내를 확인했습니다.
- 동일 좁은 화면의 전후 캡처와 데스크톱 화면을 screenshots/에 보관했습니다. 실제 휴대폰 기기 테스트와 수업 효과 검증은 아직 하지 않았습니다.

### 2026-11-23: 난이도 선택

- 예제 5문장에 하(큰 의미 단위), 중(구 단위), 상(단어 단위)을 적용했습니다. 기본값은 중입니다.
- 같은 문장의 뜻과 단어 순서를 유지하면서 조각 크기만 달라집니다. 하의 구분은 문장별로 직접 지정했습니다.
- 난이도를 바꾸면 현재 문장의 조립 상태는 초기화되지만, 난이도별 완료·오답·힌트 횟수는 현재 활동 세션에서 각각 유지됩니다. 오답 복습도 현재 난이도를 따릅니다.
- 직접 만든 기존 활동은 교사가 입력한 구분을 유지하며 난이도 선택을 비활성화합니다.
- 예제를 파일로 내보내고 다시 가져오는 경우 난이도 구분도 함께 전달합니다.
- 새로고침, 활동 변경, 전체 다시 연습 시 진행 기록이 초기화됩니다.

실제 작업한 날에 변경 이유와 함께 커밋합니다. 날짜를 조작하거나 강제 푸시·커밋 합치기를 하지 않습니다. Sites 소스 저장소는 제출용 Public GitHub 저장소와 다릅니다.
