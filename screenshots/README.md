## 영상에 사용할 때

초안과 개선 후 화면을 나란히 보여주며 '수준에 맞게 같은 문장의 조각 크기를 고를 수 있도록 바꿨다'고 설명합니다. 이는 **하나의 개선 사례**입니다. 이미지가 4장이라고 전후 비교 3회를 확보했다고 표시하지 않습니다.

다음 개선부터는 변경하기 전에 화면을 먼저 저장하고, 변경 후 같은 문장·모드·화면 크기로 저장합니다. 기존 이미지를 덮어쓰지 않고 날짜와 변경 이름을 넣습니다.
